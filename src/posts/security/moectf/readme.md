# MoeCTF 2024

MoeCTF 2024 新生赛的题解集合。

::: info 比赛信息

欢迎来到 MoeCTF 2024，这是由西电信息安全协会（XDSEC）主办的一场精彩绝伦的信息安全夺旗比赛！本次比赛面向 24 级新生，为各位带来一场前所未有的技术之旅。无论你是否具备计算机专业背景，只要你怀揣对技术的向往，对黑客世界充满好奇，都能在这里体验到纯粹的快乐，找到属于自己的闪耀时刻。

:::

完整比赛信息与题目可在[西电 CTF 终端 -> 练习场](https://ctf.xidian.edu.cn/training/10)找到。
